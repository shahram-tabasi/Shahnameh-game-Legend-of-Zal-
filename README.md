# افسانه زال | Legend of Zal

یک بازی پلتفرمر-ماجراجویی برگرفته از داستان **زال، فرزند سیمرغ** در شاهنامه فردوسی.
این مخزن شامل **دموی فنی قابل بازی (مرحله ۱)** و **اسکلت کامل پروژه** برای هر ۸ مرحله فصل اول است.

> هدف این نسخه: ساخت یک دموی قابل ارائه به سرمایه‌گذار، و سپس تکمیل بازی کامل.

---

## ۱. اجرای دمو

نیازی به نصب چیزی نیست. فقط فایل `index.html` را در مرورگر باز کن.

برای تجربه بهتر (و جلوگیری از محدودیت‌های مرورگر) می‌توانی یک سرور محلی ساده اجرا کنی:

```bash
# با پایتون
python3 -m http.server 8000
# سپس باز کن: http://localhost:8000
```

روی موبایل: همان آدرس را در مرورگر گوشی باز کن؛ کنترل‌های لمسی به‌صورت خودکار ظاهر می‌شوند.

## ۲. کنترل‌ها

| عمل | کیبورد | لمسی |
|-----|--------|------|
| حرکت | کلیدهای جهت / `A` `D` | دکمه‌های ◀ ▶ |
| پرش | `Space` / `W` / ↑ | دکمه «پرش» |
| عقاب (از مرحله ۳) | `E` | دکمه «عقاب» |
| تأیید / بازگشت | `Enter` / `Esc` | لمس روی صفحه |

**هدف مرحله ۱:** بالا رفتن از کوه البرز، جمع‌آوری میوه و آب، فرار/مقابله با گرگ‌ها و گربه کوهی،
شکست **گرگ پیر کوهستان** (با پریدن روی سرش)، و رسیدن به **سکوی مقدس سیمرغ**.

## ۳. ساختار پروژه

```
.
├── index.html              # نقطه ورود
├── css/style.css           # استایل و کنترل‌های لمسی
├── js/
│   ├── utils.js            # توابع کمکی + داده هر ۸ مرحله (STAGES)
│   ├── input.js            # ورودی کیبورد/لمس/ماوس
│   ├── audio.js            # افکت‌های صوتی WebAudio
│   ├── scene.js            # کلاس پایه صحنه + مدیر صحنه + دکمه UI
│   ├── game.js             # حلقه اصلی و راه‌اندازی
│   ├── entities/
│   │   ├── player.js       # زال (فیزیک، جان، انیمیشن)
│   │   ├── enemy.js        # گرگ، گربه کوهی، باس
│   │   ├── item.js         # میوه و آب
│   │   └── eagle.js        # عقاب همراه (مکانیک امضای بازی)
│   └── scenes/
│       ├── menu.js         # منوی اصلی
│       ├── stageSelect.js  # انتخاب مرحله (نمای ۸ مرحله)
│       ├── stage1.js       # مرحله ۱ — کاملاً قابل بازی
│       └── placeholder.js  # نگه‌دارنده مراحل ۲ تا ۸
└── docs/GDD.md             # سند طراحی بازی (Game Design Document)
```

## ۴. مکانیک امضای بازی: عقاب همراه

از مرحله ۳ به بعد، عقاب ایرانی همراه زال می‌شود. با نگه‌داشتن دکمه عقاب،
عقاب یک نگهبان/دشمن را برای **مدت محدودی** سرگرم می‌کند تا تو فرصت کنی بقیه را از پای درآوری.
اگر دیر کنی، عقاب خسته می‌شود، شکست می‌خورد و به زمین می‌افتد (زمان انتظار افزایش می‌یابد).
این منطق در `js/entities/eagle.js` پیاده‌سازی شده و آماده استفاده در مراحل بعدی است.

## ۶. تبدیل به اپ اندروید

این بازی با وب‌تکنولوژی ساخته شده تا روی هر دستگاهی اجرا شود. برای خروجی اندروید:

- **Apache Cordova** یا **Capacitor**: بسته‌بندی همین فایل‌ها در یک اپ بومی (ساده‌ترین راه).
- در صورت نیاز به گرافیک سنگین‌تر در آینده، می‌توان منطق بازی را به **Godot** منتقل کرد
  (داده مراحل در `STAGES` و سند GDD مستقل از موتورند و قابل انتقال‌اند).

## ۷. توسعه بعدی (پیشنهادی)

1. جایگزینی گرافیک برداری فعلی با اسپرایت‌های نقاشی‌شده به سبک مینیاتور ایرانی.
2. افزودن موسیقی و صداگذاری.
3. ساخت مرحله ۲ (پرواز سیمرغ) به‌عنوان مرحله دوم قابل بازی.
4. سیستم ذخیره پیشرفت (localStorage).

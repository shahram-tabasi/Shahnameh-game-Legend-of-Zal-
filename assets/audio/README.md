# فایل‌های صوتی روایت

این فایل‌ها با اسکریپت ساخته می‌شوند (در مخزن خالی است تا با اجرای دستور پر شود):

```bash
python3 -m pip install edge-tts   # یک‌بار
npm run narration                 # ساخت همهٔ mp3ها با صدای نورال فارسی
```

خروجی: `stage1-intro.mp3` … `stage8-win.mp3`.
بازی این فایل‌ها را پخش می‌کند؛ اگر نباشند، به صدای مرورگر (speechSynthesis) برمی‌گردد.
